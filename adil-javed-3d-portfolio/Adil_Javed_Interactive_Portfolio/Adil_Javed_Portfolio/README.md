# Adil Javed — Interactive Portfolio

A responsive React + Vite portfolio with scroll-reveal motion, interactive service doors, app showcases, QA report downloads, client feedback and contact links.

## Included
- Original Adil portrait supplied for the portfolio
- Original screenshots for Habit Tracker, Namaz Tracker, GolfCoachNow and NutriTrack
- Google Play links for the three published apps
- QA work samples: Dragons of Camelot, Wham Bam, Inqui AI, Vantage Point and ReelRecs
- Client review excerpts and Freelancer profile highlights

## Run locally
1. Install Node.js 18 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Build
Run `npm run build`. Vite writes the production site to `dist/`.

## Deploy on Vercel
Import this repository and use:
- Framework preset: Vite
- Root directory: `.` (leave empty)
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

All project images and downloadable reports are in `public/assets`.
